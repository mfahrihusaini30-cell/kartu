Database pelanggan

Data tersimpan di perangkat ini. Pindahkan ke Google Sheets / Excel lewat CSV, atau otomatis lewat Apps Script di bawah.

Sambung ke Google Sheets

Halaman ini tidak bisa mengirim data langsung ke situs lain. Untuk sinkron otomatis, pasang Apps Script ini di Sheet Anda (Extensions → Apps Script → Deploy sebagai Web App), lalu pakai di aplikasi yang Anda host sendiri.

function doPost(e){
 var d=JSON.parse(e.postData.contents);
 var s=SpreadsheetApp.getActive().getSheetByName(d.sheet);
 d.rows.forEach(function(r){s.appendRow(r)});
 return ContentService.createTextOutput('ok');
}
function doGet(){
 var v=SpreadsheetApp.getActive()
  .getSheetByName('Member').getDataRange().getValues();
 return ContentService.createTextOutput(JSON.stringify(v))
  .setMimeType(ContentService.MimeType.JSON);
}
